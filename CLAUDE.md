# Klarsignal nettside – regler

- Dette kodeområdet er offentlig. Legg aldri inn hemmeligheter, kundedata, interne dokumenter eller kode fra agentplattformen.
- Skriv all tekst på norsk bokmål, kort og tydelig.
- Ikke lov noe tjenesten ikke leverer ennå, og ikke finn på tall, kundesitater eller resultater.
- Ingen informasjonskapsler, sporing eller tredjeparts skript uten at personvernerklæringen oppdateres først.
- Endringer går via pull request til `main`.
